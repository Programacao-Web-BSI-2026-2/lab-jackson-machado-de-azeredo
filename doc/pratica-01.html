Registro da Prática 01

Disciplina

Programação para Web

Objetivo

Aprender os fundamentos da linguagem HTML e compreender a estrutura básica de uma página web.

Conteúdos Estudados

  • Estrutura de documentos HTML
  • Tags de título e parágrafo
  • Listas ordenadas e não ordenadas
  • Criação de hiperlinks
  • Organização de arquivos em pastas

Tags HTML Utilizadas

  • <html>: define o documento.
  • <head>: informações da página.
  • <body>: conteúdo visível.
  • <h1>: título principal.
  • <p>: parágrafo.
  • <a>: hiperlink.
  • <ul>: lista não ordenada.
  • <ol>: lista ordenada.
  • <li>: item de lista.

Conclusão

A prática permitiu compreender a organização de páginas HTML e a navegação entre arquivos.
