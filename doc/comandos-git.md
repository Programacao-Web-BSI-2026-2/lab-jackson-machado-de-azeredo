# Guia de Comandos Git

## O que é Git?

Git é um sistema de controle de versões utilizado
para acompanhar as alterações em projetos.

## Comandos básicos

### git init

Inicializa um repositório Git.

### git status

Mostra o estado atual dos arquivos do projeto.

### git add .

Adiciona os arquivos modificados à área de preparação.

### git commit

Registra as alterações no histórico do projeto.

Exemplo:
`git commit -m "Adicionando atividades"`

### git push

Envia os commits locais para o repositório remoto.

Exemplo:
`git push origin main`

### git pull

Atualiza o repositório local com as alterações remotas.

### git clone

Cria uma cópia de um repositório remoto.

## GitHub Pages

O GitHub Pages permite publicar sites estáticos
diretamente a partir de um repositório no GitHub.

## Conclusão

O Git facilita o gerenciamento das versões do
projeto e o GitHub permite armazenar e publicar
os arquivos desenvolvidos.
