Guia de Comandos Git

O que é Git?

Git é um sistema de controle de versões utilizado para acompanhar alterações em projetos.

Comandos Básicos

git init

Inicializa um repositório Git.

git status

Mostra o estado atual dos arquivos.

git add .

Adiciona os arquivos à área de preparação.

git commit

Registra as alterações no histórico.

git commit -m "Adicionando atividades"

git push

Envia os commits para o repositório remoto.

git push origin main

git pull

Atualiza o repositório local.

git clone

Clona um repositório remoto.

GitHub Pages

O GitHub Pages permite publicar sites estáticos diretamente a partir de um repositório GitHub.

Conclusão

O Git facilita o gerenciamento das versões e o GitHub permite armazenar e publicar projetos.
