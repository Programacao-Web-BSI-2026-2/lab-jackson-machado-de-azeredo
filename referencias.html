Tags Básicas

As tags HTML são utilizadas para estruturar o conteúdo de uma página.

<h1> ao <h6>: Definem a hierarquia de títulos.

<p>: Define um parágrafo.

<ul>: Cria uma lista não ordenada.

<ol>: Cria uma lista ordenada.

<li>: Define um item de lista.

Links e Imagens

Links permitem navegar entre páginas e diferentes seções de um site.

<a href="...">: Tag âncora usada para criar hiperlinks.

<img src="...">: Tag utilizada para inserir imagens.

Tipos de Links

  • Relativo: Acessa arquivos do próprio projeto.
  • Absoluto: Acessa endereços completos da internet.
  • Âncora: Navega entre seções da mesma página.
